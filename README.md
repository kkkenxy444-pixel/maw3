# MAW3 Android Mod Lab

Community research workspace for exploring the feasibility of modding **Machines at War 3** on Android, using Android-only tools.

## Goals

1. Inspect the APK structure and identify asset/configuration formats.
2. Compare Android data layouts with documented PC modding approaches.
3. Test small, reversible changes to unit stats in an authorized personal copy.
4. Document findings, limitations, and reproducible procedures.

## Status

**Awaiting APK structural analysis.** Nothing has yet been verified to be moddable on Android.

## Repository policy

- Do not upload original game APKs, proprietary game assets, extracted packages, or signing keys.
- Only share original scripts, documentation, metadata summaries, and legally redistributable patches.
- Work from backups, preserve save data, and test offline first.
- This is an independent, unofficial fan research project, not affiliated with Isotope 244.

## Android-only workflow

Upload a legitimately obtained APK **privately for inspection**, not to this public GitHub repository. Inspect asset layout first; plan modifications only after identifying supported files.
